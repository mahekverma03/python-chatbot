# Rule-Based Chatbot

A simple Python chatbot that uses keyword matching to respond to greetings, farewells, and common questions. Built as part of a Python programming internship project.

## Features
- Responds to greetings (hi, hello)
- Answers common questions (name, how are you)
- Responds to thanks
- Help command to see available options
- Type 'bye' to exit the chat

## How to Run
python bot.py
## Example
Aap: hi
Bot: Hello! Kaise ho?
Aap: what is your name
Bot: My name is Bot.
Aap: bye
Bot: Bye bye! Take care!
